# SmartTracker Enterprise

SmartTracker is a multi-organisation ticketing and support application. The repository contains an Express/Mongoose API and an Expo React Native frontend.

## Requirements

- Node.js 20 or newer and npm.
- MongoDB 6.0 or newer for the API.
- SMTP settings to complete email verification during account registration.

## Run locally

1. Start MongoDB locally, or use a MongoDB URI you are authorized to access.
2. Configure and start the backend:

   ```sh
   cd backend
   npm ci
   cp .env.example .env
   ```

   Set a unique `JWT_SECRET` of at least 32 characters in `backend/.env` (for example, generate one with `openssl rand -base64 48`). Configure SMTP values to receive registration and verification email. The default MongoDB URI is `mongodb://127.0.0.1:27017/smarttracker`.

   ```sh
   npm start
   ```

3. In another terminal, configure and start the mobile app:

   ```sh
   cd frontend/mobile
   npm ci
   cp .env.example .env
   ```

   Set the appropriate `EXPO_PUBLIC_API_URL_*` value for web, Android emulator, or a physical device as described in the [mobile setup guide](./frontend/mobile/README.md), then run:

   ```sh
   npm start
   ```

The API health check is at <http://localhost:5000/api/v1/health>. Interactive API documentation is at <http://localhost:5000/api-docs>.

## Tests

```sh
cd backend
npm test
```

Backend tests require MongoDB and use the separate `smarttracker_phase2_test` database by default. Frontend tests are run from `frontend/mobile` with `npm test`.

## Database and handoff

The [database reference](./docs/database.md) documents the Mongoose collections, relationships, and indexes. There is no database dump or reusable application seed dataset in this repository; accounts and tickets are created through the application flow. Test records are generated by the automated tests.

Never commit `.env` files, database credentials, tokens, or real user/customer records. The tracked `.env.example` files contain placeholders and safe defaults only. For backend and API details, see the [backend guide](./backend/README.md).
